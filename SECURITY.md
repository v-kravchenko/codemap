# Security

codemap reads a project's compiled classes, resources and git history and never sends them anywhere;
only `codemap init` runs the project's Gradle, the way a build would.

Report a vulnerability privately through
[GitHub's security advisories](https://github.com/v-kravchenko/codemap/security/advisories/new), not
in a public issue. Expect an answer within a week. Fixes go into the latest release only.
